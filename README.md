# Генератор блок-схем из Python (drawio)

Веб-приложение: пользователь вставляет код на Python, на выходе получает файл
`.drawio` с блок-схемой. Один файл содержит несколько страниц: `main` и по одной
на каждую функцию (`def`). Перед скачиванием схему можно посмотреть прямо на
странице.

## Возможности

- Разбор Python через стандартный модуль `ast` (без сторонних парсеров).
- Поддержка: `assign`, `input`, `print`, `if/elif/else`, `while`, `for`,
  `def`, `return`, `break`, `continue`, `try/except` (тело разбирается,
  `except` помечается как «прочее»).
- Каждая функция — отдельная страница; на главной странице рисуются её вызовы
  (кликабельные в предпросмотре и со ссылками между страницами в `.drawio`).
- Единственный Terminator «Начало» и «Конец» на каждой странице.
- Укладка с точками слияния (merge) и раздельными каналами — минимум пересечений.
- Предпросмотр схемы в браузере (SVG) с масштабированием.
- Скачивание готового файла `.drawio` для [app.diagrams.net](https://app.diagrams.net).

## Сопоставление конструкций

| Python                  | Фигура drawio                          |
|-------------------------|----------------------------------------|
| Начало / Конец          | Terminator (`rounded=1;arcSize=50`)    |
| `x = ...`, `x += ...`   | Process (прямоугольник)                |
| `input(...)`            | Параллелограмм (ввод)                  |
| `print(...)`            | Параллелограмм (вывод)                 |
| `if / elif / else`      | Ромб (условие); `Да` слева, `Нет` справа |
| `while`                 | Ромб (условие) + обратная дуга         |
| `for`                   | Шестиугольник + обратная дуга          |
| `def`                   | отдельная страница; вызов — Process    |
| `return`                | дуга к единственному узлу «Конец»      |
| не распознано (`class`, `with`, …) | блок «прочее» с исходным кодом |

## Требования

- Python 3.9+ (используется `ast.unparse`).
- Единственная зависимость — `flask`.

## Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Tr1nside/drawio-generate.git
cd drawio-generate

# 2. Создать и активировать виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить сервер
python3 app.py
```

После запуска в консоли появится баннер с адресом:

```
  ┌─────────────────────────────────────────────┐
  │  Генератор блок-схем (drawio)               │
  └─────────────────────────────────────────────┘
  Откройте:   http://127.0.0.1:5000
  Режим:      обычный
  Слушает:    127.0.0.1:5000
```

Откройте в браузере <http://127.0.0.1:5000>.

### Параметры запуска

```bash
python3 app.py --port 8080        # другой порт
python3 app.py --host 0.0.0.0     # доступ из локальной сети
python3 app.py --debug            # авто-перезапуск и подробные логи
```

Те же значения можно задать переменными окружения `HOST`, `PORT`, `DEBUG`.
Сервер отдаёт `/healthz` для проверки доступности.

Альтернативный запуск через Flask CLI:

```bash
flask --app app run --debug
```

## Устранение неполадок

### Браузер показывает «403 Forbidden» на http://127.0.0.1:5000

Сервер здесь ни при чём — запрос перехватывает HTTP-прокси (VPN/Clash/корпоративный
прокси), который не пропускает `localhost`. При запуске приложение предупреждает об
этом, если видит переменные `HTTP_PROXY`/`ALL_PROXY`.

Что сделать:

1. **Браузер:** добавьте `127.0.0.1` и `localhost` в список исключений прокси
   («No proxy for» / «Исключения»).
2. **Терминал:** `export NO_PROXY=127.0.0.1,localhost` (и `no_proxy`).
3. Попробуйте открыть `http://localhost:5000` вместо `http://127.0.0.1:5000` —
   некоторые прокси различают эти адреса.
4. Как проверить, что дело в прокси: `curl --noproxy '*' http://127.0.0.1:5000/`
   вернёт `200`.

## Использование

1. Вставьте Python-код в поле слева.
2. Нажмите «Построить блок-схему».
3. Проверьте схему в панели предпросмотра (кнопки `−`/`+` меняют масштаб,
   вкладки переключают страницы `main` и функции).
4. Нажмите «Скачать .drawio» и откройте файл в app.diagrams.net.

## Проверка

Скрипт прогоняет генерацию на примерах и проверяет XML, набор фигур и
единственность начала/конца:

```bash
python3 test_generate.py
```

Результаты сохраняются в каталог `out/`.

## Структура проекта

```
drawio-gen/
  app.py            # Flask: GET "/", POST "/convert"
  parser.py         # ast -> IR
  ir.py             # dataclass-узлы IR
  layout.py         # IR -> координаты
  drawio.py         # координаты -> mxGraph XML
  preview.py        # координаты -> SVG-предпросмотр
  requirements.txt  # flask
  templates/index.html
  static/app.js
  static/style.css
  test_generate.py  # проверка генерации
```

Пайплайн: `ast.parse` → IR → layout (x/y) → XML/SVG → ответ фронтенду →
скачивание `.drawio`.
