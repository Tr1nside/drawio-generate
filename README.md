# Генератор блок-схем из кода (drawio)

Веб-приложение: пользователь вставляет код на **Python** или **C#**, на выходе
получает файл `.drawio` с блок-схемой. Один файл содержит несколько страниц:
`main` и по одной на каждую функцию/метод. Перед скачиванием схему можно
посмотреть прямо на странице.

## Возможности

- Разбор Python (стандартный модуль `ast`) и C# (`tree-sitter`).
- Поддержка: присваивания, ввод/вывод, `if/elif/else` (C#: `if/else if/else`),
  `while`, `for`, `foreach`, `switch`, `do-while`, `def`/методы, `return`,
  `break`, `continue`, `try/except`/`try/catch/finally`.
- Каждая функция/метод — отдельная страница; вызовы кликабельны в предпросмотре
  и содержат ссылки между страницами в `.drawio`.
- Единственный Terminator «Начало» и «Конец» на каждой странице.
- Подряд идущие однотипные простые операторы объединяются в одну фигуру
  (например, два `print` — одна нода с двумя строками).
- Укладка с точками слияния (merge) и раздельными каналами — минимум пересечений.
- Автоопределение языка или выбор вручную; выбор сохраняется в браузере.
- Предпросмотр схемы в браузере (SVG) с масштабированием.
- Скачивание готового файла `.drawio` для [app.diagrams.net](https://app.diagrams.net).

## Сопоставление конструкций

| Python / C#                                   | Фигура drawio                            |
|-----------------------------------------------|------------------------------------------|
| Начало / Конец                                | Terminator (`rounded=1;arcSize=50`)      |
| `x = ...`, `x += ...`, выражения              | Process (прямоугольник)                  |
| `input(...)` / `Console.ReadLine`/`Read`      | Параллелограмм (ввод)                    |
| `print(...)` / `Console.WriteLine`/`Write`    | Параллелограмм (вывод)                   |
| `if / elif / else` / `if / else if / else`    | Ромб; `Да` слева, `Нет` справа            |
| `switch` (C#)                                  | цепочка ромбов (`x == value`)             |
| `while`, `do-while`                           | Ромб (условие) + обратная дуга            |
| `for`, `foreach`                              | Шестиугольник + обратная дуга             |
| `def` / метод                                 | отдельная страница; вызов — Process       |
| `return`                                      | дуга к единственному узлу «Конец»         |
| `break` / `continue`                          | дуги к выходу/голове цикла                |
| не распознано (`class`, `with`, …)            | блок «прочее» с исходным кодом            |

## Требования

- Python 3.10+.
- Зависимости: `flask`, `tree-sitter-language-pack` (тянет `tree-sitter`).
  Грамматика C# подгружается language-pack при первом использовании, поэтому
  в первый раз нужен доступ в сеть (далее берётся из кэша).

## Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Tr1nside/drawio-generate.git
cd drawio-generate

# 2. Создать и активировать виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить сервер
python3 app.py
```

После запуска в консоли появится баннер с адресом:

```
  ┌─────────────────────────────────────────────┐
  │  Генератор блок-схем (drawio)               │
  └─────────────────────────────────────────────┘
  Откройте:   http://127.0.0.1:5000
  Режим:      обычный
  Слушает:    127.0.0.1:5000
```

Откройте в браузере <http://127.0.0.1:5000>.

### Параметры запуска

```bash
python3 app.py --port 8080        # другой порт
python3 app.py --host 0.0.0.0     # доступ из локальной сети
python3 app.py --debug            # авто-перезапуск и подробные логи
```

Те же значения можно задать переменными окружения `HOST`, `PORT`, `DEBUG`.
Сервер отдаёт `/healthz` для проверки доступности.

Альтернативный запуск через Flask CLI:

```bash
flask --app app run --debug
```

## Устранение неполадок

### Браузер показывает «403 Forbidden» на http://127.0.0.1:5000

Сервер здесь ни при чём — запрос перехватывает HTTP-прокси (VPN/Clash/корпоративный
прокси), который не пропускает `localhost`. При запуске приложение предупреждает об
этом, если видит переменные `HTTP_PROXY`/`ALL_PROXY`.

Что сделать:

1. **Браузер:** добавьте `127.0.0.1` и `localhost` в список исключений прокси
   («No proxy for» / «Исключения»).
2. **Терминал:** `export NO_PROXY=127.0.0.1,localhost` (и `no_proxy`).
3. Попробуйте открыть `http://localhost:5000` вместо `http://127.0.0.1:5000` —
   некоторые прокси различают эти адреса.
4. Как проверить, что дело в прокси: `curl --noproxy '*' http://127.0.0.1:5000/`
   вернёт `200`.

## Использование

1. Выберите язык (Python / C# / Авто) или оставьте «Авто».
2. Вставьте код в поле слева.
3. Нажмите «Построить блок-схему».
4. Проверьте схему в панели предпросмотра (кнопки `−`/`+` меняют масштаб,
   вкладки переключают страницы `main` и функции).
5. Нажмите «Скачать .drawio» и откройте файл в app.diagrams.net.

## Проверка

Тесты написаны как обычные скрипты (запускаются без зависимостей) и как
pytest-совместимые функции.

```bash
# всё сразу (если установлен pytest)
pytest

# либо по отдельности, без pytest
python3 test_parsers.py    # парсеры, реестр, автодетект, ошибки
python3 test_layout.py     # инварианты укладки и XML (.drawio)
python3 test_app.py        # HTTP-API Flask через test client
python3 test_generate.py   # сквозная генерация и метрики (0 пересечений)
```

Тестовые примеры лежат в `fixtures/python/` и `fixtures/csharp/`, поэтому
набор самодостаточен. Результаты генерации сохраняются в каталог `out/`.

Зависимость для запуска через pytest — `requirements-dev.txt`.

## Структура проекта

```
drawio-gen/
  app.py                 # Flask: GET "/", POST "/convert", /healthz
  ir.py                  # язык-нейтральный IR
  parsers/
    base.py              # LanguageParser (ABC), ParseError
    python_parser.py     # ast -> IR
    csharp_parser.py     # tree-sitter -> IR
    registry.py          # реестр парсеров (DIP)
  parser.py              # shim обратной совместимости
  layout.py              # IR -> координаты (+ объединение операторов)
  optimizer.py           # объединение подряд идущих простых операторов
  drawio.py              # координаты -> mxGraph XML
  preview.py             # координаты -> SVG-предпросмотр
  fixtures/python/       # примеры Python для тестов
  fixtures/csharp/       # примеры C# для тестов
  templates/index.html
  static/app.js
  static/style.css
  test_parsers.py        # юнит-тесты парсеров и реестра
  test_layout.py         # инварианты укладки и XML
  test_app.py            # тесты HTTP-API
  test_generate.py       # сквозная генерация и метрики
  pytest.ini             # конфигурация pytest
```

Пайплайн: `parser.parse` → IR → `layout` (x/y) → XML/SVG → ответ фронтенду →
скачивание `.drawio`.
